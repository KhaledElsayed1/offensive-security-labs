# 📱 Mobile Application Penetration Testing

This repository contains my hands-on mobile application security labs, assessments, and write-ups focused on Android application penetration testing.

The goal is to understand mobile application security from both static and dynamic perspectives while following industry methodologies such as OWASP MASVS and the OWASP Mobile Top 10.

---

## 🎯 Objectives

- Perform Android application security assessments
- Identify common mobile vulnerabilities
- Practice reverse engineering techniques
- Analyze APK files using professional tools
- Document findings with remediation recommendations

---

## 🔍 Topics Covered

- Static Analysis
- Dynamic Analysis
- Reverse Engineering
- Android Manifest Review
- APK Decompilation
- Hardcoded Secrets
- Insecure Data Storage
- Authentication & Authorization
- API Security Testing
- SSL Pinning Analysis
- Local Storage Analysis
- SharedPreferences Inspection
- Network Traffic Analysis
